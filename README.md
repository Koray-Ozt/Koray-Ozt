### Featured project

#### [Atlas API](https://github.com/Koray-Ozt/Atlas_Api)
**FastAPI · MongoDB · Docker · Pytest · GitHub Actions**

A compact, documented REST API for order management, designed to demonstrate backend engineering fundamentals rather than feature count.

- Typed request validation, clear HTTP semantics, and centralized error handling
- Layered code with isolated business rules and MongoDB access
- Structured request logging and optimistic concurrency checks
- Unit and integration tests with automated CI
- Reproducible local setup with Docker Compose

**Measured MongoDB index optimization:** On a local benchmark of 200,000 synthetic orders, compound indexes reduced median query latency from **81.13 ms to 0.66 ms** and **101.92 ms to 0.59 ms** for two query patterns. Results are environment-specific, not production performance claims.

[Explore the code](https://github.com/Koray-Ozt/Atlas_Api) · [Benchmark methodology and results](https://github.com/Koray-Ozt/Atlas_Api/blob/main/benchmarks/RESULTS.md)
