### Selected projects

#### [PasRead](https://github.com/Koray-Ozt/Pasread) · Hotel operations and AI document processing
**Python · CustomTkinter · Vision LLMs · OpenCV · Android/Java · Browser Extensions**

A Windows desktop application developed around hotel front-desk workflows, connecting identity-document processing with guest registration and operational tools.

- Extracts passport and ID data using vision models, with MRZ checks, field-level review states, and fallback handling
- Manages guest records, in-house lists, checkout workflows, and registration documents
- Connects to an Android guest-form application over a local HTTPS service
- Integrates with hotel workflows through a browser extension and local bridge
- Includes multilingual guest forms and local data-protection measures

*The repository contains application code; real guest and identity data are not included.*

#### [CodeForge Bench](https://github.com/Koray-Ozt/CodeForge-Bench) · Software engineering evaluation
**Python · Pytest · Docker · Ruff · GitHub Actions**

A reproducible benchmark for evaluating human- or AI-generated code patches against realistic engineering problems.

- Five tasks covering concurrency, performance, refactoring, code review, and backend behavior
- Visible and hidden tests, reference solutions, and intentionally flawed candidate patches
- Resource-limited Docker execution with structured JSON and Markdown reports
- Deterministic checks and benchmark measurements, with documented sandbox limitations

[Explore the benchmark](https://github.com/Koray-Ozt/CodeForge-Bench) · [Evaluation results](https://github.com/Koray-Ozt/CodeForge-Bench/blob/main/results/verify.md)

#### [Atlas API](https://github.com/Koray-Ozt/Atlas_Api) · Order management backend
**FastAPI · MongoDB · Pydantic · Docker · Pytest**

A focused REST API project covering validated order workflows, data modeling, query optimization, and automated testing.

- Order CRUD, filtering, pagination, status transitions, and optimistic concurrency checks
- Layered application structure, structured logs, and consistent error responses
- Unit and MongoDB integration tests, with GitHub Actions CI
- Reproducible synthetic-data benchmarks comparing indexed and unindexed queries

**Local benchmark:** With 200,000 synthetic orders, median query times fell from **81.13 ms to 0.66 ms** and **101.92 ms to 0.59 ms** across two query patterns. These are environment-specific measurements, not production claims.

[Explore the API](https://github.com/Koray-Ozt/Atlas_Api) · [Benchmark details](https://github.com/Koray-Ozt/Atlas_Api/blob/main/benchmarks/RESULTS.md)
